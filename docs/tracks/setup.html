Clone the CBSA Application Source Code

Create a ~/CBSA directory, open it in Bob IDE, then clone the source code from a terminal.

1
Create the workspace folder & open it in Bob IDE
Create a CBSA directory in your home directory. In Bob IDE, click File → Open Folder and select the ~/CBSA directory. Trust the workspace when prompted — without it Bob IDE enters Restricted mode.
2
Open a terminal & clone the repository
In Bob IDE, open a terminal via Terminal → New Terminal, then run:
git clone https://github.com/fbh112/CBSA-base-source.git
Outputs: Once cloned, you will find the following subdirectories under your workspace: 
CBSA-base-source/
  ├── README.md
  ├── bms_src/       (CICS BMS screens)
  ├── cobol_copy/    (copybooks)
  └── cobol_src/     (29 COBOL programs)
3
Verify IBM Bob Premium Package for Z access

Verify your access to IBM Bob Premium Package for Z.

1
Login to Bob
Use the blue Login to Bob button on the right-hand Bob chat panel. When Bob asks for permission to open an external website, choose Open. Sign in with your IBM ID. Once logged in, Bob will prompt you to install the IBM Bob Premium Package for Z — accept the installation.
2
Verify extensions
In Bob IDE, open the Extensions panel (Cmd/Ctrl+Shift+X) and verify that these extensions are installed:
  • IBM Bob Premium Package for Z v3.0.0+
  • IBM Z Open Editor v6.6.0+
  • Zowe Explorer v3.5.0+
  • Mermaid (latest)
If they are not installed, contact your IBM representative, as you do not have entitlement for the IBM Bob Premium Package for Z
3
Verify Z Modes
Look at the mode selector in the bottom-right corner of the Bob chat panel. Click it to open the mode list and confirm that Z Code and Z Architect are present. If they are missing, the Premium Package for Z is not activated — contact your IBM representative.

The CBSA Application

You will work on a real banking application that simulates bank teller operations: the CICS Banking Sample Application (CBSA).

Technical characteristics

AttributeDetails
PlatformIBM z/OS with CICS Transaction Server V5.4+
LanguageIBM Enterprise COBOL for z/OS
DatabaseIBM Db2 V12+
Interface3270 terminals with BMS (Basic Mapping Support)
ArchitectureTransaction processing with online and batch programs

Business functionalities

  • Customer creation and management
  • Bank account creation and management
  • Account inquiry
  • Transfers between accounts
  • Account debit / credit
  • External credit agency simulation

Complexity

  • 29 COBOL programs
  • 37 copybooks
  • 9 BMS screens
  • 4 Db2 tables
  • Multi-tier architecture (presentation, business logic, data)

Initial situation

You have just joined the maintenance team for this application. You have the source code but:

  • ❌ No up-to-date technical documentation
  • ❌ No program inventory
  • ❌ Undocumented architecture
  • ❌ Business rules not formalized
  • ❌ Dependencies between programs unknown
  • ❌ Impact of modifications difficult to assess
Your mission: Use IBM Bob Premium Package for Z to analyze and document this application in a few hours instead of several weeks.
⚠️ Note on AI non-determinism: Bob relies on AI agentics which is non-deterministic. You may see slight differences from the sample results shown in the labs. This is normal — Bob always reaches the goal but may take different paths.
