# Bob4z-a-thon


A Hackathon to Discover IBM Bob Premium Package for Z

## Three labs are offered in this hackathon:

+ The main lab [LabDiscoverCBSA](./EN/1-LabDiscoverCBSA_EN.md) will allow you to discover the CBSA COBOL application. You will be able to inventory the application, discover the architecture, document and query programs or functions of the application. You can then study an evolution of the application with the corresponding implementation.<b>nb: chapter 3 "Lab preparation" lists the pre-reqs to the three labs.</b>

+ The next lab [LabDiscoverCBSAGlobal](./EN/2-LabDiscoverCBSAGlobal_EN.md) allows you to extend the analysis to the application's frontend. This enables you to enrich the business process analysis.

+ Finally, the lab [LabSkillBuilder-Refactor](./EN/3-LabSkillBuilder-Refactor_EN.md) allows you to experiment with creating a skill to optimize COBOL program generation.



## French version

Un Hackathon pour découvrir IBM Bob Premium Package for Z 

## Trois labs sont proposés dans cet hackathon

+ Le lab principal [LabDiscoverCBSA](./FR/1-LabDiscoverCBSA.md) qui va permettre de découvrir l'application COBOL CBSA. On pourra notamment faire l'inventaire de l'application, découvrir l'architecture, documenter et interroger sur des programmes ou fonctions de l'application. On pourra ensuite étudier une évolution de l'application avec la mise en oeuvre correspondante. <b>nb: le chapitre 3 "Préparation du lab" décrit les prérequis aux trois labs.</b>

+ Le lab suivant [LabDiscoverCBSAGlobal](./FR/2-LabDiscoverCBSAGlobal.md) permet d'étendre l'analyse au frontend de l'application. Cela permet d'étoffer l'analyse des processus métier

+ Enfin le lab [LabSkillBuilder-Refactor](./FR/3-LabSkillBuilder-Refactor.md) permet d'expérimenter la création d'un skill pour optimiser la génération de programmes COBOL.
