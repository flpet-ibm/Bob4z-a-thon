# Bob4z-a-thon


A Hackathon to Discover IBM Bob Premium Package for Z

## Four labs are offered in this hackathon:

+ The main lab [LabDiscoverCBSA](./EN/1-LabDiscoverCBSA_EN.md) — estimated 3–4h - will allow you to discover the CBSA COBOL application. You will be able to inventory the application, discover the architecture, document and query programs or functions of the application. You can then study an evolution of the application with the corresponding implementation.<b>nb: the chapter 3 [Lab preparation](./EN/1-LabDiscoverCBSA_EN.md#3-lab-preparation) lists the pre-reqs to the three labs.</b>

+ The next lab [LabDiscoverCBSAGlobal](./EN/2-LabDiscoverCBSAGlobal_EN.md) — estimated 1–2h (for those interested in the Java frontend) - allows you to extend the analysis to the application's frontend. This enables you to enrich the business process analysis.

+ The next lab [LabSkillBuilder-Refactor](./EN/3-LabSkillBuilder-Refactor_EN.md) — estimated 1–2h - allows you to experiment with creating a skill to optimize COBOL program generation.

+ Finally, the lab [LabOptimizeSQL&DB2Config](./FR/4-LabOptimizeSQL&DB2Config.md) — estimated 1–2h - allows you to work on the optimisation of SQL statements and DB2 configuration of the application CBSA.
  

1 - Discover CBSA — estimated 3–4h
2 - Discover CBSA Global — estimated 1–2h (for those interested in the Java frontend)
3 - Skill Builder: Refactor — estimated 1–2h
4 - Optimise DB2 statements - estimated 1-2h
